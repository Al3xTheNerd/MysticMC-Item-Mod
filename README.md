# MysticMC Item Browser

This mod does a few things related to the custom items on MysticMC, using the API provided (by me) at https://items.mysticmc.co/.

- Want to see what those fancy new wings would look like when paired with your skin? This mod can do that!
- Want to figure out which items can cut down a whole tree at once? This mod can do that!
- Want to look at logs but can't remember whether that helmet is secretly an evil piece of paper or a feather? This mod can tell you!
- Did you see someone pull an item in chat, but have no clue what it does? Now you can hover over it in chat to see the item lore!

## Item List

You can either set a keybind in the vanilla keybinds menu or use `/itemlist` to pull up the list of all items currently processed. From there you can sort the items by keywords, tags, crate, or rarity.

## Item Preview

You can either press `Preview` in the `/itemlist` menu, or you can run `/itemlist preview start` to start a preview session. A preview session will hide all of your inventory items, and let you customize your preview inventory to your heart's content! Extreme care has been taken to ensure that none of your items are deleted for real.

1. Find an item that you would like to preview.
2. Click the item, then click inventory at the top of your screen. (or if you want to preview multiple items, shift click the item to toss it in a random slot to be sorted later)
3. On the Inventory tab, move your item(s) as desired to see what it would look like in different slots.
4. You can close preview mode at any time to use f5 (or a freecam mod) to view yourself at any angle.
5. To reopen the preview inventory, just press whatever button opens your inventory normally!
6. When you're done pretending you have the fancy items you want, click `End` in the preview screen, or use `/itemlist preview end` to go back to your normal inventory.

## /whatisthat

This command will tell you what the 'base item' of any custom item is. Not very useful for the majority of people, but very helpful for staff members of the server.

## In Chat Previews

- By default when a player rolls a custom item from a crate, you might not know what it does, instead of going through all the effort of searching it up, now you can just hover over it to see the item lore! You can also click it, and from there either open the item on the Item Site, or add it to your preview mode!
- Kill messages containing a Mystic Item can also be hovered over!

## Item Uploads

This is a feature for Supplementary Site Maintainers, when a new crate comes out, you can use this to add every item in the crate to the Queue, to be processed and added to the database! Reach out to AlexTheNerd on Discord if you have questions on this feature. (fair warning if you don't know what this is, then it's probably not your problem to deal with)
